How to use a theme

Hover a tile and hit ⧉ tokens to copy its full :root block — colours, radius, font stacks. Each theme also sets a surface treatment (flat / soft / hard / glow) worth copying with the colours.

How to change one

Edit themes_data.py, run python build.py, and every page plus this index regenerates. Add a theme by appending one T(...) line.
